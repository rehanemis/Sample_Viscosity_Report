# Sample_Viscosity_Report
he user types the lubricant name, ISO VG, VI, viscosity at 40 °C and 100 °C, the date and the min / normal / max operating temperatures. Example values are already filled in. The ASTM D341 chart redraws automatically, with the red line, the 40 °C and 100 °C markers, and orange markers showing the viscosity at each operating temperature.
